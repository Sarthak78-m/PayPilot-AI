1. FEATURES IMPLEMENTED [IMPLEMENTED]
--------------------------------------

  - Natural Language Invoice Extraction: Accepts freeform text descriptions (e.g. "I developed a website for Acme Corp. The agreed amount is 2500 USD, payment is due on December 15, 2026.") and extracts structured invoice data.
  - Server-Side Authenticated Endpoint: `POST /api/invoices/generate`, strictly protected by cookie-based Supabase authentication.
  - Anti-Hallucination & Factual Guardrails: Strict system instructions forbid inventing customer details, tax rates, prices, dates, or payment terms.
  - Missing Fields & Clarification Detection: Identifies missing required fields (`customer_name`, `description`, `amount`, `currency`) in a `missing_fields` array and populates `clarification_notes` and `is_complete` boolean flag.
  - Untrusted Output Sanitization: Model output is treated as untrusted input; sanitized, numerical precision rounded to 2 decimal places (`NUMERIC(12,2)`), currency validated against supported currencies, and invalid dates rejected.
  - Strict Non-Persistence & Integrity: Generation never sets `id`, `user_id`, or `status`, and never inserts records into the database. The user reviews and explicitly saves drafts via the existing `POST /api/invoices` endpoint.
  - Robust Error Handling: Handlers for API key absence (503), timeouts (504), rate limits / quotas (429), malformed model JSON (502), and oversized prompts (400).

3. API ENDPOINT CONTRACT & EXAMPLES [IMPLEMENTED & TESTED]
-----------------------------------------------------------

Endpoint: POST /api/invoices/generate
Authentication: Required (Supabase session cookie)
Content-Type: application/json

Request Body:
  {
    "prompt": "I developed a website for Acme Corp. The agreed amount is 2500 USD, payment is due on December 15, 2026."
  }

Success Response (200 OK — Complete Draft):
  {
    "status": "ok",
    "data": {
      "draft": {
        "customer_name": "Acme Corp",
        "customer_email": null,
        "description": "Full-stack web application development",
        "amount": 2500.00,
        "currency": "USD",
        "due_date": "2026-12-15"
      },
      "missing_fields": [],
      "is_complete": true,
      "clarification_notes": null
    }
  }

Success Response (200 OK — Incomplete / Missing Details):
  Request: { "prompt": "I did some consulting for Wayne Enterprises yesterday." }
  Response:
  {
    "status": "ok",
    "data": {
      "draft": {
        "customer_name": "Wayne Enterprises",
        "customer_email": null,
        "description": "Consulting services",
        "amount": null,
        "currency": null,
        "due_date": null
      },
      "missing_fields": ["amount", "currency"],
      "is_complete": false,
      "clarification_notes": "Amount and currency were not specified in the description."
    }
  }

Validation Error Responses:
  400 Bad Request: Empty/missing prompt or prompt exceeding 5000 characters.
  401 Unauthorized: Unauthenticated request.
  429 Too Many Requests: Gemini rate limit / quota exceeded.
  502 Bad Gateway: Gemini API error or malformed model output.
  503 Service Unavailable: Missing server GEMINI_API_KEY.
  504 Gateway Timeout: Gemini API request timed out (> 15s).


4. GEMINI MODEL & SDK INTEGRATION DETAILS [IMPLEMENTED & CODE-REVIEWED]
------------------------------------------------------------------------

  - SDK: `@google/generative-ai` (^0.24.1)
  - Client Singleton: `backend/src/lib/gemini/gemini-client.js` with `import "server-only";`
  - Model: `process.env.GEMINI_MODEL || "gemini-2.5-flash"`
  - Configuration:
    - Temperature: 0.1 (low temperature for deterministic, factual extraction)
    - Response MIME Type: `application/json`
    - Timeout: 15 seconds promise race guard to prevent server hanging
  - Security: API key accessed only server-side via `process.env.GEMINI_API_KEY`. Never returned or exposed in client responses.
