2. ARCHITECTURAL & SECURITY PRESERVATION
--------------------------------------------------------------------------------
- Server-Only Isolation:
  "import 'server-only';" strictly preserved in:
    backend/src/lib/gemini/gemini-client.js
    backend/src/lib/gemini/generate-invoice.js
- Singleton Client Pattern:
  `getGeminiClient()` caches singleton instance initialized with `process.env.GEMINI_API_KEY`.
- No Client Exposure:
  API keys are kept strictly in server-side environment variables (.env.local).
- Non-Persistence In AI Generation:
  POST /api/invoices/generate only returns structured draft data with missing_fields and clarification_notes.
  Never writes directly to Supabase; user must review and explicitly save via POST /api/invoices.
- Identity & Status Isolation:
  No model output can control or inject `id`, `user_id`, or `status`.
